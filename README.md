# ОПОРА — Платформа психологічної самодопомоги та самодіагностики

«ОПОРА» — це веб-додаток для психологічної самодопомоги, орієнтований на підтримку людей у стані тривоги, паніки, вигорання та стресу. Працює **100% автономно у браузері** без передачі персональних даних на зовнішні сервери.

---

## 🌟 Основні можливості

- **Миттєве заспокоєння**:
  - Інтерактивна дихальна техніка (квадратне дихання 4-4-4-4) із супроводом м'якого заспокійливого звуку.
  - Покрокова техніка заземлення «5-4-3-2-1» за методикою КБТ.
  - SOS-паніка кнопка для швидкого приборкання гострого нападу тривоги.
- **Клінічні самотести**:
  - Опитувальники PHQ-9 (депресія) та GAD-7 (тривожність).
  - Анонімне збереження результатів та історії в `localStorage`.
- **Щоденник емоцій**:
  - Фіксація емоційного стану, рівня напруги та нотаток з аналітикою та трекінгом динаміки.
- **База знань**:
  - Науково доведені психоосвітні статті з пошуком за ключовими словами та тегами.
- **Особистий план безпеки**:
  - Індивідуальний антикризовий алгоритм із можливістю збереження та друку.
- **Аудіо-атмосфера**:
  - Аудіофони (спів солов'я, бамбукова флейта, дощ, морський прибій), що синтезуються у браузері за допомогою Web Audio API.

## 🚀 Інструкція із запуску та розгортання на GitHub

### 1. Локальний запуск для розробки

```bash
# Клонувати репозиторій
git clone https://github.com/ваш-юзернейм/назва-репозиторію.git
cd назва-репозиторію

# Встановити залежності
npm install

# Запустити сервер розробки
npm run dev
```

Додаток буде доступний за адресою `http://localhost:3000`.

---

### 2. Автоматичне розгортання на GitHub Pages (Рекомендовано)

У репозиторій уже додано workflow файл `.github/workflows/deploy.yml`.

1. Завантажте код у ваш репозиторій на GitHub:
   ```bash
   git add .
   git commit -m "Initial commit for OPORA"
   git branch -M main
   git remote add origin https://github.com/ваш-юзернейм/назва-репозиторію.git
   git push -u origin main
   ```
2. Перейдіть у налаштування вашого репозиторію на GitHub:
   - **Settings** -> **Pages**.
   - У розділі **Source** виберіть **GitHub Actions**.
3. Після кожного коміту у гілку `main` сайт буде автоматично збиратися та публікуватися на GitHub Pages!

---

### 3. Ручне розгортання через `gh-pages`

Якщо ви хочете розгорнути сайт вручну зі свого ПК:

```bash
npm run deploy
```

Ця команда автоматично збере проєкт (`npm run build`) та опублікує вміст папки `dist` у гілку `gh-pages`.

## 🛠 Технології

- **React 19** + **TypeScript**
- **Vite** (з налаштованим відносним шляхом `base: './'` для GitHub Pages)
- **Tailwind CSS v4**
- **Lucide React** (іконки)
- **Recharts** (аналітика та графіки щоденника)
- **Web Audio API** (синтез звуку без зовнішніх файлів)

---

## 🔒 Приватність

Усі дані (щоденник емоцій, план безпеки, результати тестів) зберігаються **виключно локально у браузері користувача (`localStorage`)** і ніколи не відправляються на жоден сервер.
